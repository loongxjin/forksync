# Issue Tracker

This repo uses a **local markdown** issue tracker.

## Workflow

- Issues live as markdown files under `.scratch/<feature>/` in this repo.
- Each issue is a separate `.md` file.
- Use directories to group issues by feature or milestone.
- The `to-issues` skill writes issues here as markdown files.
- The `triage` skill moves issues between states by renaming files or updating frontmatter.
