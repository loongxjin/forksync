# Domain Docs

## Layout

**Single-context** — one `CONTEXT.md` + `docs/adr/` at the repo root.

## Consumer Rules

- Read `CONTEXT.md` at the repo root to learn the project's domain language.
- Read `docs/adr/` for past architectural decisions.
- If `CONTEXT.md` is missing, infer domain language from `README.md` and source code.
